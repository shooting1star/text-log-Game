# Project-C
C-language,project

A lightweight, console-based text RPG game implemented in C. Designed to run smoothly and quickly in any terminal environment without complex dependencies, it features game state tracking and text-based logging to save and review your adventure history.

C언어로 구현된 가벼운 콘솔 기반 텍스트 RPG 게임입니다. 복잡한 설치 없이 콘솔 환경에서 빠르고 가볍게 실행할 수 있으며, 게임 진행 상황을 텍스트 로그로 저장하고 불러올 수 있는 기능을 제공합니다.

## ✨ Key Features

* **Lightweight Execution**
  * Written in pure C with zero external library dependencies, making it fast and portable.
  * 외부 라이브러리 의존성 없이 순수 C언어로 제작되어 어디서나 가볍게 실행 가능합니다.

* **Text-Based RPG**
  * Immersive text interface where player choices and combat unfold in real time.
  * 텍스트 인터페이스를 통해 플레이어의 선택과 전투 상황을 실시간으로 확인하고 진행합니다.

* **Log Saving**
  * Automatically records major events and combat history into text log files for easy review anytime.
  * 모험 중 발생한 주요 이벤트와 전투 기록을 텍스트 파일로 저장하여 언제든지 다시 확인할 수 있습니다.
